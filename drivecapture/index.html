From screen to shareable link in four beats

No saving, no dragging files into Drive, no copying share links. You capture; the rest happens on its own.

  1. 1

    Press a shortcut

    Option + Shift + 1 to 4, from any app.

    カチッ
  2. 2

    Pick the area

    Drag a region, or take the whole screen. Recordings get a 3-2-1 countdown.

    シュッ
  3. 3

    It uploads

    Straight to the Drive folder you chose, with a view link your team can open.

    ビュン
  4. 4

    Paste anywhere

    The link is in your clipboard. Drop it into Slack, a GitHub issue, or a test sheet.

    ペタッ

Four shortcuts to remember

All of them can be changed in Settings → Shortcuts.

⌥option⇧shift1
Screenshot a regionPress Space to pick a window instead.
⌥option⇧shift2
Screenshot the whole screenThe screen your pointer is on.
⌥option⇧shift3
Record a regionPress it again to stop recording.
⌥option⇧shift4
Record the whole screenOr stop from the red timer in the menu bar.

Press Esc while picking an area or during the countdown to cancel. Nothing is uploaded.

It talks back

Every finished upload gets a sound, so you know the link is ready without looking. Pick anime voices, macOS sounds, or your own audio file.

  • やめてLink copiedYamete kudasai — the default when an upload finishes.
  • えぇっ？Upload failedAn anime-girl gasp. The file stays on your Mac, one click to retry.
  • なに？！NANI?!For when you want more drama.

Slap your MacBook

DriveCapture reads the hidden motion sensor in Apple Silicon MacBooks. Give it a slap and it protests — harder slaps are louder. Sensitivity is adjustable so typing doesn't set it off.

Install in about five minutes

DriveCapture is built from source on your Mac. You need macOS 15 or later and a terminal.

The repository is private for now. Ask the owner to add your GitHub account as a collaborator before cloning. Accounts @zigexn.vn can sign in right away; other Google accounts need their own OAuth client (see the README).

  1. Install Apple's command line tools

    Skip this if you already have them — the command will tell you.

    xcode-select --install

  2. Clone the repository

    git clone https://github.com/nguyyenanh-zigexn/driveCapture.git && cd driveCapture

  3. Create a signing certificate (once)

    Keeps macOS from asking for Screen Recording permission again after every update. It lives in its own keychain.

    scripts/setup-signing.sh

  4. Build and install

    Copies DriveCapture to /Applications and opens it. Look for the camera icon in the menu bar.

    scripts/make-app.sh --install

  5. Set it up in the app

    • Settings → Account → Sign in with Google.
    • Settings → Folder → choose where captures go.
    • Press Option + Shift + 1, allow Screen Recording in System Settings, then reopen the app.

  6. Update later

    git pull && scripts/make-app.sh --install
